# Procedencia del proyecto

Este repositorio personal importa la base de `design-software-frontend-platform` recibida mediante una descarga ZIP de la rama `develop` del proyecto original. La descarga no conserva el historial Git y este repositorio independiente no constituye un fork de GitHub.

Origen del proyecto: https://github.com/code-sena/design-software-frontend-platform

El código importado corresponde a la base recibida y no se presenta como desarrollo propio de quien realiza la importación. Se conservan los archivos originales, sus avisos de autoría y las condiciones de licencia que los acompañen. Esta nota no concede una licencia nueva.

La rama `main` conserva el README inicial del repositorio personal. La base descargada se registra en `develop`; los cambios posteriores para integrar el dominio Reference Data se registrarán por separado.

Este proyecto se utiliza como dependencia para ejecutar y demostrar el dominio Reference Data dentro del web-shell. El trabajo individual asignado corresponde a HU-REF-020 y al reto R1 de Reference Data Service. Un pull request en este repositorio personal no integra cambios al repositorio original ni acredita como propia la base importada.
